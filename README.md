# SISGED - Front-end

MVP front-end do SISGED preparado para publicação em hospedagem estática.

## Estrutura
- `index.html` — página inicial
- `cadastrar_aula.html` — tela demonstrativa de cadastro de aula
- `cadastrar_instrutor.html` — tela demonstrativa de cadastro de instrutor
- `consulta.html` — tela de consultas
- `css/` — estilos
- `js/` — JavaScript
- `img/` — imagens

## Limitações
Esta versão é somente front-end. Recursos que dependem de PHP, sessão, banco de dados ou APIs não são executados pelo GitHub Pages/Cloudflare Pages. Os formulários de cadastro são demonstrativos, conforme a proposta de MVP estático da atividade.
